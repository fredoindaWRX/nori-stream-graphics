# Nori Stream Graphics

Ten free animated OBS scene graphics from **FredoIndaWRX**. Use them for Nori builds, coding streams, and your next creator project.

## Download

[Download Nori Stream Graphics v1](https://github.com/fredoindaWRX/nori-stream-graphics/raw/refs/heads/main/Nori-Stream-Graphics-v1.zip)

Download the ZIP above and extract the entire folder. Open `index.html` to preview all ten scenes. Keep the files together so the symbol and styles load correctly.

## Set up in OBS

1. Create a scene and add a **Browser Source**.
2. Enable **Local file** and choose a scene HTML file from the extracted `scenes` folder.
3. Set the Browser Source to **3840 × 2160** for a 4K canvas, or **2560 × 1440** for a 1440p canvas.
4. For Coding or Nori Demo, place your selected Window Capture or Game Capture **below** the graphic. For a monitor variant, choose the matching display in your separate Display Capture source.
5. Make a short local recording. Check the scene, readable text, transitions, microphone, and consenting guest audio before going live.

Starting Soon, Break, and Ending fill the screen. These graphics do not mute audio or control OBS. The community scene is a graphic, not a connected Discord chat feed.

## Customize and get help

Edit the HTML text and `theme.css` for your channel. Use your own approved branding for a separate creator identity. Read `USE.txt` for the pack's usage note.
